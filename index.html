Sheet Merge Check

Effective date: 10 November 2026. Contact: hwu121380@gmail.com.

A narrow Google Sheets add-on that merges selected tabs with the same or similar headers and produces a check report (row counts, header mismatches, exact duplicate rows, and blank key fields).

Developer

Wu Hang, an individual. Contact: hwu121380@gmail.com.

Status

This site hosts the privacy policy and terms for the add-on. The add-on is not listed on the Google Workspace Marketplace yet. Paid Pro checkout is not live.

How it handles data

The add-on runs inside the spreadsheet where you install it, using Google Apps Script. It reads and writes only that spreadsheet. It does not send your sheet data to a server operated by Wu Hang. This matches the current source in src/.
