# Sheet Merge Check

A narrow Google Sheets add-on by **Wu Hang** that merges selected tabs and produces a check report.

This repository also hosts the public [Privacy Policy](privacy.html) and [Terms of Use](terms.html) for GitHub Pages.

The add-on is not listed on the Google Workspace Marketplace yet. Paid checkout is not live.

## Source

Prototype Apps Script files are in [`src/`](src/), licensed under the MIT License. The merge-and-check logic is adapted from [csv-merge-check](https://github.com/hwu121380-afk/csv-merge-check), also MIT-licensed.
